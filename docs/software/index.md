# Software

Guides for the CFD solvers and other tools used in the lab. Each tool has its own section, and any job scripts for running it on Vega live in that section alongside the page that explains them.

If you haven't run a job on Vega before, read the [Vega getting started pages](../cluster/vega/index.md) first. The pages here assume you know how to connect, load modules and submit a job.
